# Contributing

Thanks for helping improve Base64 Encoder & Decoder.

## Before opening a pull request

- Keep the project static: plain HTML, CSS, and JavaScript with no build tooling or runtime dependencies.
- Preserve the privacy promise: do not add analytics, tracking, cookies, storage, uploads, or server-side processing.
- Use semantic HTML and keyboard-accessible controls.
- Test both conversion modes with plain text, Unicode text, and invalid Base64.
- Check the layout at narrow and wide viewport sizes, in both light and dark themes.

## Development

Open `index.html` in a modern browser. No installation or build step is needed.

## Reporting problems

Open a GitHub issue with a clear description, steps to reproduce, expected behavior, actual behavior, and browser details. Do not include sensitive information in an issue.
